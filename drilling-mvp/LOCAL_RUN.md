# Run locally

This app needs Python and a terminal. GitHub Pages does not execute Python/Streamlit applications.

1. Install Python 3.10 or newer.
2. Download or clone this repository.
3. Open a terminal in the `drilling-mvp` folder.
4. Create and activate a virtual environment (optional but recommended).
5. Install dependencies:
   `pip install -r requirements.txt`
6. Start the app:
   `streamlit run app.py`
7. Open the local URL printed by Streamlit, usually `http://localhost:8501`.

For public hosting, deploy the `drilling-mvp` folder to a Streamlit-compatible hosting service only after reviewing the data handling and privacy implications. Do not upload confidential datasets to a public demo.
