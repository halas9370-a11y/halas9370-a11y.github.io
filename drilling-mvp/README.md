# HalaLoya AI Drilling Assistant

Research prototype for drilling CSV data analysis.

## Initial scope
- Upload and inspect CSV datasets.
- Check missing values, duplicate rows, and column types.
- Explore drilling variables with charts.
- Prepare data-quality reports.

## Important limitations
This is a research prototype, not a validated prediction system. It must not be used for operational drilling or safety decisions. Dataset licenses and permissions must be verified before reuse or publication.
